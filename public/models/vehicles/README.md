# Kenney Car Kit vehicles

Source: <https://kenney.nl/assets/car-kit>

The `sedan.glb`, `hatchback-sports.glb`, and `suv.glb` files are unmodified
assets from Kenney's Car Kit 3.1. The pack is released under Creative Commons
Zero (CC0); attribution is not required.

These models were selected for the browser and Decentraland targets because
they are glTF 2.0 GLBs with no Meshopt or KTX2 extensions, one material/texture
each, and approximately 2,000-2,500 triangles per model. Each GLB references the
shared PNG palette at `Textures/colormap.png` and uses the standard
`KHR_texture_transform` extension. Keep that relative folder structure intact.
